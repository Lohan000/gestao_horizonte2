## Sistema de Gestão Empresarial
# Introducão
- Os colaboradores colaboradores controlam clientes, produtos, pedidos e relatórios por meio
de anotações e planilhas separadas. Porém está os resultados são cadastros duplicados,
informações desencontradas e dificuldades para acompanhar a operação.

# Objetivo do protótipo e funcionalidades previstas
E o objetivo desse prototipo é resolver isso com suas funcionalidades: Consultar informações
básicas dos clientes, Organizar itens comercializados, Acompanhar solicitações de pedidos e
Observar resultados da operação.

# Tecnologias utilizadas

Utilizado o vscode, html, css, md e gitignore.

# Requisitos para visualizar as páginas

depois de aberto o index, se pode acessar de duas maneiras as paginas do site ou por meio dos links azuis mostrado abaixo para as paginas, ou pelo os botões do site para cima.
